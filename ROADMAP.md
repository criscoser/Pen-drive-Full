# Roadmap

> 🇧🇷 Pontos de melhoria anotados · 🇺🇸 Planned improvements

## ✅ Feito / Done
- Instalação automática do Windows 11 com conta local / Unattended Windows 11 install with a local account
- Pós-formatação: Wi-Fi, limpeza, programas, Office, Chrome padrão, drivers e BIOS Lenovo / Post-install: Wi-Fi, cleanup, apps, Office, default Chrome, Lenovo drivers and BIOS
- Teste de estresse: Prime95 (processador) e FurMark 2 (placa de vídeo) / Stress test: Prime95 (CPU) and FurMark 2 (GPU)
- Janela única de escolha no início (Wi-Fi, programas, otimização) / Single choice window at the start (Wi-Fi, apps, optimization)
- Mais rápido: Office em segundo plano, checagens em lote, tempo de cada etapa no relatório / Faster: Office in the background, batched checks, per-step timing in the report
- Pula programas já instalados / Skips apps already installed
- Chrome sem perguntas / Chrome without prompts
- Menu do Ventoy entra no Windows instalado após 10 s / Ventoy menu boots the installed Windows after 10 s
- Relatório visual em HTML e resumo de todas as máquinas / Visual HTML report and machines summary
- Privacidade máxima e otimização genérica (qualquer marca) / Maximum privacy and generic optimization (any brand)
- Wi-Fi escolhido na hora pelo usuário, com opção de salvar no pendrive / Wi-Fi picked on the spot by the user, optionally saved on the drive
- Configurações e senha do Wi-Fi fora do código (`config.json`) / Settings and Wi-Fi password out of the code (`config.json`)
- Linux Mint XFCE, Kali Linux, Windows 10, SystemRescue e netboot.xyz / Linux Mint XFCE, Kali Linux, Windows 10, SystemRescue and netboot.xyz
- Teste de portas USB (USB Device Tree Viewer, CrystalDiskMark) / USB port testing
- Lista de SHA-256 oficiais das ISOs / Official ISO SHA-256 list
- Modo só otimizar para PC em uso, com ponto de restauração / Optimize-only mode for PCs in use, with a restore point
- Painel gráfico escuro (`PAINEL.bat`) com abas Otimizar/Instalar/Remover e andamento ao vivo / Dark GUI panel with Optimize/Install/Remove tabs and live progress
